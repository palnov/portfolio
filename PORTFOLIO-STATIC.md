# Новая статическая главная

`index.html`, `styles.css`, `script.js`, `assets/` — самостоятельное портфолио на HTML, CSS и JavaScript, без сборки и зависимостей. Существующие CMS, проекты и production-конфигурация не менялись.

Локальный просмотр: `node serve.cjs`, затем открыть http://127.0.0.1:4173. Можно открыть `index.html` напрямую. Сервер предварительного просмотра отдаёт только публичные файлы нового сайта.

В `script.js` находятся 12 прежних проектов и настройка `KWORK_URL`. Skripta Publisher вынесен в отдельную карточку в HTML. Адрес конкретного профиля Kwork ещё нужно подставить; сейчас ссылки ведут на главную биржи. Кнопки заказа не отправляют сообщения автоматически. Вспомогательное окно составляет текст для ручной отправки.

Фото и старые обложки перенесены из `cms/public/portfolio-assets/`, оптимизированы в WebP. Обложка Skripta — скриншот реального сайта. Шрифт Golos Text загружается из Google Fonts, при недоступности используется Arial. Новые библиотеки не установлены.

Есть фильтры проектов, раскрытие полного списка, интерактивный демо-бот, лёгкий параллакс, появления секций, поддержка reduced motion, клавиатурная навигация и адаптивная вёрстка. Демо-бот показывает сценарии и не обращается к Telegram или CRM.

Публикация этой версии ещё не выполнялась. Перед интеграцией в production следовать DEPLOYMENT.md: корневая статическая главная сама по себе не заменяет текущий ресурс portfolio-cms.
